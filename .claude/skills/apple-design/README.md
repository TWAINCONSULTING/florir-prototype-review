## What it covers

Apple's interface-design and motion principles translated to the web: response
latency, 1:1 direct manipulation, spring animations, velocity inheritance and
momentum projection, interruptible/reversible transitions, translucent materials
and depth, typography (optical sizing, tracking, leading), and reduced-motion.

## Using it

Claude Code loads this automatically for anyone working in this repo — it
triggers on gesture-driven UI, drag/swipe/sheet interactions, spring animation,
and related design review. You can also invoke it explicitly with
`/apple-design`.
